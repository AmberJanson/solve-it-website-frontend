About

Goal

This website was created for the SOLVE-IT framework developed by Christopher Hargreaves, Eoghan Casey and Harm van Beek. The purpose of this framework is to collect all data on techniques, weaknesses and mitigations in the field of digital forensics in one central location. This tool can then be used by people in the field to conduct research and/or investigations. The intention is to continuously expand this framework with new techniques that will be needed in the rapidly developing digital environment. The SOLVE-IT website is designed to present this data in a clearly structured and accessible manner, so that it can be found quickly and easily by all its users.

Contribute

To contribute to the goal of continuously expanding the framework with data on techniques, weaknesses, and mitigations, you can also submit your own data. Currently, these contributions are managed via Github. Read more about how the contribution process precisely works. In addition, if you have comments on existing techniques, weaknesses, or mitigations, you can go directly from the detailpage to the location on Github where this data is stored.
